Methodology

What each agent measures, how the composite blends them, and the discipline that keeps the backtest honest.

Universe

Nifty 200 constituents on NSE India, 11 GICS sectors, reconstituted semi-annually. The seed list lives at config/universe_seed.csv.

EODHD symbols use the .NSE suffix (e.g. RELIANCE.NSE). Ticker renames like Zomato → Eternal are tracked.

Scoring

Every factor is cross-sectionally percentile-ranked, winsorized at the 5/95 extremes. Ranks are averaged within an agent and scaled to 0–100.

Missing data → neutral 50 and row flagged imputed=true. No agent is forced into a decision it can't support.

Technical agent

  • 1M, 3M, 6M, 12M total return
  • 60-day annualized volatility (inverted)
  • Distance to SMA-50 and SMA-200
  • 14-day RSI
  • Planned: MACD histogram, Bollinger %B, Stochastic, ADX, 14-day ATR/price, OBV momentum

Momentum agent

  • 12-1 momentum (ret_12m − ret_1m) — the classic Jegadeesh-Titman factor
  • 3-month return
  • 6-month return

Keep momentum separate from the technical agent so you can weight them independently.

Sentiment agent

  • 30-day mean news polarity (EODHD scoring)
  • 30-day headline volume
  • Thin-coverage guard: if < 3 headlines in 7 days, mark imputed
  • Planned: analyst revisions, surprise direction, social buzz, event risk

Fundamental agent

  • Value: P/E, EV/EBITDA, P/B, P/S, FCF yield, PEG
  • Quality: ROE, ROIC, gross/operating/net margin, Piotroski F-score
  • Growth: revenue growth, EPS growth, surprise history, forward EPS growth
  • Balance sheet: debt/equity, current ratio, interest coverage
  • Shareholder yield: dividend + buyback yield

Sector-neutral ranks inside each pillar. Winsorized at 5/95.

Combiner

Three modes:

  • Weighted composite — weighted average of the four agent scores. Sidebar weights normalize to 100%.
  • Consensus — a stock is only a candidate if k of 4 agents agree it's above / below the cutoff.
  • Hybrid — 70% weighted composite + 30% weakest-agent score (penalizes a stock that one agent hates).

Sector cap: no more than max_names_per_sector on each side. Buffer: an existing position stays in the book until it drops below n + buffer to cut turnover.

Point-in-time discipline

Every fact table carries two dates:

  • effective_date — the date the fact describes (price date, earnings period end, insider transaction date)
  • known_date — the earliest date we could have observed it (file ingest date, SEC filing date, press release timestamp)

At backtest time t, every query filters on known_date ≤ t. There is no API in the codebase that lets a factor see data it couldn't have had — try toggling the date in the dashboard, the agent output rolls forward exactly as it would have at the time.

Costs & execution assumptions

  • Slippage: 5 bps per fill
  • Commission: 0 bps (NSE direct)
  • Short borrow: 50 bps annual, prorated
  • Min trade: ₹100 equivalent
  • Execution: pre-open on next trading day after the rebalance signal
